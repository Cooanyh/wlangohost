# Security policy

## Supported release

The latest stable release is the supported version for security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when available. Do not publish credentials, Wi-Fi passwords, device addresses, or unredacted logs in a public issue. Include the WlanGO version, Windows build, and a concise reproduction that does not expose private network data.

WlanGO does not collect telemetry. Local logs are size-limited and omit Wi-Fi credentials, SSIDs, and client addresses.
